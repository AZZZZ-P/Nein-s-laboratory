# 三栏对照阅读器（Interlinear Reader）

## Overview

产出一个不依赖网络的单文件 HTML：原文 / 逐句译文 / 逐词释义三栏并排，句子级双向定位，
可逐条记点评并汇总成读书感悟。全部工作量的 80% 在**数据**（`data.json`），
模板与脚本已经写好，不要重新发明。

## 工作流

### 1. 直接开工，不要提问

范围、标题、文件名全部有默认值。用户没指定就按下面的表**自己定并开始做**，
不要为了「确认一下」而发消息——这些决定可逆、成本低、用户随时可以改。

| 项目 | 默认 |
| --- | --- |
| 逐词覆盖 | 摘要 + 关键词 + 正文全部小节 + 脚注 + 致谢/利益冲突/数据可用性声明 |
| 不逐词 | 参考文献列表（整节从略，`byline` 里注明「参考文献从略」）、表格数值、图注（保留原文整句即可） |
| 逐句译文 | 页面上每一条正文句子都要有中栏译文，含脚注 |
| `meta.titleEn` | 首页标题原样（保留冒号、问号）；PDF 元数据与正文不一致时以正文为准 |
| `meta.titleZh` | 直译，用词与正文译法一致，副标题用「：」接；不要润色成畅销书名 |
| `meta.slug` | 从 `titleEn` 取 3–5 个实词，小写连字符，去掉冠词/介词 |
| 输出位置 | 项目根 `三栏对照阅读_<slug>.html`；中间产物进 `_work/`（`source.txt`、`data.json`、`data.bak.json`） |
| 交付方式 | 生成并验收完直接报告结果与用法，不问「要不要继续」 |

只有三种情况才开口问：PDF 读不出任何文本；原文语言无法确定目标译语；
篇幅明显超出单次可处理量（正文 ≳3 万英文词）需要确认是否只做正文。
用户说过的任何一条以用户为准，覆盖上表。

### 2. 抽取原文

**默认用 Read 工具直接分页读 PDF**（`pages: "1-20"`），把每页文本抄进 `_work/source.txt` 并加
`=== PAGE n ===` 标记。环境里装了 PyMuPDF / pdfplumber / poppler 任一种时，脚本更快，
且会顺带清掉软连字符与 fi/fl 连字；三种都没有时脚本只会提示改用 Read，不会崩：

```bash
python3 scripts/extract_pdf.py paper.pdf -o _work/source.txt
```

抽取文本必然有断行、页眉页脚、字距拉开（`s h o r t`）等噪声，切句前先按页校对干净——
以抽取文本为准，不要凭记忆补写原文。

### 3. 切句并逐词注释，写成 data.json

结构、字段与逐词数组 `t` 的硬规则见 `references/data-format.md`，务必先读它。要点：

- 按逻辑句子切分（缩写、`e.g.`、`Vis-à-vis`、引号内的句末标点后不断句），句子不跨段。
- `t` 覆盖句中每个实词与短语，顺序严格从左到右；词面必须能在原文中定位。
- 长文分节增量写：每完成一节就追加进 JSON，别把整篇塞进一次 Write。
- 立刻存一份 `data.bak.json`，之后的修补脚本一律「读 bak → 写 data」，保证可重跑。

### 4. 校验 → 修复 → 直到全绿

```bash
python3 scripts/build_reader.py _work/data.json --check
```

要求 `miss=0 backward=0 empty_gloss=0`。`--check` 会分类打印问题词条及其所在句子。
按 `references/data-format.md` 末尾的表格修：收缩被污染的词面、把 `/` 串起来的后续词条拆回独立
条目、剔除多词组内部的重复注释（**顺序很重要，重复条目要在收缩之前删**）、
并警惕压缩索引带来的假命中（`February 2` 能命中 `February 2023`）。

### 5. 生成

```bash
python3 scripts/build_reader.py _work/data.json -o 三栏对照阅读_全文.html
```

脚本把紧凑 JSON 注入 `assets/reader-template.html` 的 `__DATA__`（并转义 `</`）。
标题、副标题、笔记存储键、感悟导出名全部来自 `data.json` 的 `meta`，模板本身不含任何文章信息。

### 6. 浏览器验收

按 `references/reader-internals.md` 第 6 节的清单跑：句子数、全量重算定位、点左栏只动中栏、
点中栏只动左栏、导航/快捷键两栏都动、逐词栏回到顶部、笔记存取与 digest。
断言用 `evaluate_script`（内置视图截图常不可用）。**测完清空 localStorage**，别把测试笔记留给用户。

### 7. 交付

告诉用户：双击打开即可；点任意一句原文 → 中栏定位译文，点译文 → 原文定位；
悬停词行看高亮、点词行锁定；`j/k` 或 ↑↓ 切句；`n` 打开读书笔记，选中任意文字可只点评那一段，
笔记自动存在本机，最后用「生成读书感悟 → 下载 .md」导出。
宽屏（≥1081px）才有三栏独立滚动，窄屏自动退回整页滚动。
报告里顺带一句本次的默认取舍（哪些部分逐词、参考文献从略），用户想改范围就当场重跑第 3–5 步，
不要提前拿这些取舍去征求同意。

## 功能需求（不可削减）

三栏独立滚动 · 点原文定位译文（反向同理）· 每词单独释义并可锁定高亮 · 逐条读书笔记 +
Markdown 感悟汇总（localStorage 持久化 + 复制/下载）。用户后续要求的改动要写进模板，
不要在生成后的 HTML 上直接改。

## Resources

- `assets/reader-template.html` — 阅读器模板，唯一占位符 `__DATA__`
- `scripts/extract_pdf.py` — PDF 抽文本（PyMuPDF → pdfplumber → pdftotext）
- `scripts/build_reader.py` — 校验逐词定位并注入生成单文件 HTML（`--check` 只校验，`--force` 容忍漏定位）
- `references/data-format.md` — data.json 结构、逐词注释硬规则、噪声修复对照表
- `references/reader-internals.md` — 布局/滚动/点击路由/笔记的实现不变量与验收清单
